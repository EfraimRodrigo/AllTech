3. LOADER (BARRA DE CARREGAMENTO)
================================================================================

O loader aparece ao abrir cada página — barra fina que cresce + texto.

ONDE ESTÁ:
  Cada página HTML tem um bloco <style> no <head> com o CSS do loader,
  e um bloco <script> no final do <body> com o JS do loader.

COMO AJUSTAR A VELOCIDADE:
  No bloco <style> de cada página, localize:
    animation: loaderGrow 1.4s ...   → tempo da barra crescer (padrão: 1.4s)
    animation: loaderFade 1s ...     → tempo do texto aparecer (padrão: 1s)

  No bloco <script> do loader, localize:
    setTimeout(function(){ ... }, 1200);  → tempo antes de sumir (padrão: 1200ms)

COMO ALTERAR O TEXTO:
  Em cada página, localize:
    <span class="loader-text">NOME DA PÁGINA</span>
  
  Textos atuais por página:
    index.html              → ALLTECH
    sumerios-barber.html    → SUMÉRIOS BARBER
    sumerios-retail.html    → SUMÉRIOS RETAIL
    sumerios-crm.html       → SUMÉRIOS CRM
    sumerios-commerce.html  → SUMÉRIOS COMMERCE
    zapp.html               → ZAPP
    cases.html              → CASES
    blog.html               → BLOG
    contato.html            → CONTATO
    quem-somos.html         → QUEM SOMOS
    trabalhe-conosco.html   → CARREIRAS
    privacidade.html        → PRIVACIDADE
    termos.html             → TERMOS

COMO DESATIVAR O LOADER em uma página:
  Remova o bloco <!-- PREMIUM LOADER --> do HTML
  e o bloco <!-- LOADER JS --> do final do body.

COMO ALTERAR A COR DA BARRA:
  No bloco <style>, localize:
    .loader-line { background: #00A4CC; ... }
  Substitua #00A4CC pela cor desejada.

4. TIPOGRAFIA
================================================================================

O projeto usa duas fontes do Google Fonts:
  - Inter (corpo do texto) — pesos: 300, 400, 500, 600, 700, 800, 900
  - Syne (títulos e logo) — pesos: 700, 800

COMO ALTERAR OS TAMANHOS DOS TÍTULOS:
  Em css/style.css, seção "── 3. TYPOGRAPHY ──":
    h1 { font-size: clamp(2rem, 4.5vw, 3.8rem); }
    h2 { font-size: clamp(1.5rem, 3vw, 2.5rem); }
    h3 { font-size: clamp(1.1rem, 1.8vw, 1.35rem); }

  O formato clamp(mínimo, fluido, máximo) define:
    - mínimo: tamanho em mobile
    - fluido: escala com a largura da tela
    - máximo: tamanho em desktop

COMO TROCAR A FONTE:
  1. Escolha uma fonte em fonts.google.com
  2. Em cada HTML, substitua o link do Google Fonts no <head>
  3. Em css/style.css, atualize:
     body { font-family: 'NovaNome', sans-serif; }
     h1, h2, h3 { font-family: 'NovaNome', sans-serif; }

7. FORMULÁRIO DE CONTATO (EmailJS)
================================================================================

O formulário em contato.html está estruturado mas aguarda configuração.
Quando tiver o domínio e quiser ativar o envio real:

PASSO A PASSO:
  1. Acesse https://www.emailjs.com/ e crie uma conta gratuita
  2. Crie um "Email Service" (conecte seu Gmail ou outro)
  3. Crie um "Email Template" com as variáveis:
       {{from_name}}   → nome do contato
       {{reply_to}}    → email do contato
       {{phone}}       → whatsapp
       {{interest}}    → solução de interesse
       {{message}}     → mensagem
  4. Abra js/emailjs-config.js e preencha:
       serviceId:  'service_XXXXXXX'   (do painel EmailJS)
       templateId: 'template_XXXXXXX'  (do painel EmailJS)
       publicKey:  'user_XXXXXXX'      (do painel EmailJS → Account)
  5. Em contato.html, adicione no <head>:
       <script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js"></script>
  6. Em js/main.js, na função initForms(), substitua o bloco de sucesso por:
       emailjs.init(window.emailjsConfig.publicKey);
       emailjs.sendForm(
         window.emailjsConfig.serviceId,
         window.emailjsConfig.templateId,
         form
       ).then(function(){ /* sucesso */ }, function(){ /* erro */ });

CAMPOS DO FORMULÁRIO (contato.html):
  id="nome"      → Seu Nome        (autocomplete="name")
  id="email"     → E-mail          (autocomplete="email")
  id="whatsapp"  → WhatsApp        (autocomplete="tel")
  id="solucao"   → Solução         (select)
  id="mensagem"  → Mensagem        (textarea)

8. ANALYTICS (Google Analytics + Microsoft Clarity)
================================================================================

Configuração em js/analytics-config.js

GOOGLE ANALYTICS 4:
  1. Acesse https://analytics.google.com/
  2. Crie uma propriedade → Web → copie o Measurement ID (G-XXXXXXXXXX)
  3. Em analytics-config.js, substitua:
       measurementId: 'G-XXXXXXXXXX'  →  measurementId: 'G-SEU-ID-REAL'
  4. Certifique-se que enabled: true

MICROSOFT CLARITY (mapas de calor + gravações):
  1. Acesse https://clarity.microsoft.com/
  2. Crie um projeto → copie o Project ID (número)
  3. Em analytics-config.js, substitua:
       projectId: 'XXXXXXXXXX'  →  projectId: 'SEU-ID-REAL'
  4. Certifique-se que enabled: true

ATENÇÃO: O analytics só funciona quando o site estiver publicado em HTTPS.
Localmente (file://) os scripts são carregados mas não enviam dados.

PARA DESATIVAR TEMPORARIAMENTE:
  Em analytics-config.js, mude enabled: false em qualquer serviço.

9. CHAT AO VIVO (Tawk.to)
================================================================================

Configuração em chat-config.js

COMO ATIVAR:
  1. Acesse https://www.tawk.to/ e crie uma conta gratuita
  2. Crie uma propriedade → copie o Property ID e Widget ID
  3. Em chat-config.js, substitua:
       tawkId:   'SUBSTITUA_POR_SEU_TAWK_ID'    →  seu Property ID
       widgetId: 'SUBSTITUA_POR_SEU_WIDGET_ID'  →  seu Widget ID
  4. O chat aparece automaticamente em todas as páginas que carregam chat-config.js
     (atualmente: privacidade.html e termos.html)
  
  Para adicionar em outras páginas, inclua antes do </body>:
    <script src="chat-config.js"></script>
    <script>
    if(window.chatConfig && window.chatConfig.enabled && 
       window.chatConfig.tawkId !== 'SUBSTITUA_POR_SEU_TAWK_ID'){
      var Tawk_API=Tawk_API||{};
      (function(){
        var s=document.createElement("script"); s.async=true;
        s.src='https://embed.tawk.to/'+window.chatConfig.tawkId+'/'+window.chatConfig.widgetId;
        document.head.appendChild(s);
      })();
    }
    </script>

11. SEO E META TAGS
================================================================================

ONDE ESTÃO:
  Cada página tem suas próprias meta tags no <head>.
  O arquivo seo-config.json centraliza as configurações de referência.

COMO ATUALIZAR O DOMÍNIO (quando tiver o domínio real):
  1. Em seo-config.json, atualize "url": "https://alltech.com.br"
  2. Em CADA página HTML, atualize:
     - <link rel="canonical" href="https://alltech.com.br/PAGINA.html">
     - <meta property="og:url" content="https://alltech.com.br/PAGINA.html">
     - <meta property="og:image" content="https://alltech.com.br/assets/...">
  3. Em sitemap.xml, atualize todas as <loc> com o domínio real
  4. Em robots.txt, atualize a linha Sitemap:

SITEMAP:
  Arquivo: sitemap.xml
  Atualizar o campo <lastmod> sempre que modificar uma página.
  Formato: YYYY-MM-DD (ex: 2026-05-14)
  
  Após publicar, envie o sitemap ao Google:
    https://search.google.com/search-console → Sitemaps → Adicionar sitemap

SCHEMA.ORG (index.html):
  Dois blocos JSON-LD no <head>:
  - Organization: dados da empresa (nome, endereço, telefone, redes sociais)
  - WebSite: nome e URL do site
  
  Atualize quando mudar endereço, telefone ou redes sociais.

17. DEPLOY / PUBLICAÇÃO
================================================================================

O site é estático (HTML + CSS + JS puro) — pode ser hospedado em qualquer lugar.

OPÇÕES RECOMENDADAS:

1. VERCEL (gratuito, mais fácil):
   - Acesse vercel.com → New Project
   - Conecte ao GitHub ou faça upload da pasta site/
   - Deploy automático em segundos
   - Domínio gratuito: seusite.vercel.app
   - Para domínio próprio: Settings → Domains → Add

2. NETLIFY (gratuito, similar ao Vercel):
   - Acesse netlify.com → Add new site → Deploy manually
   - Arraste a pasta site/ para a área de upload
   - Domínio gratuito: seusite.netlify.app

3. GITHUB PAGES (gratuito):
   - Crie um repositório no GitHub
   - Faça upload dos arquivos
   - Settings → Pages → Source: main branch

4. HOSPEDAGEM TRADICIONAL (cPanel, etc.):
   - Faça upload via FTP para a pasta public_html/
   - Use FileZilla ou o gerenciador de arquivos do cPanel

APÓS PUBLICAR:
  1. Atualize o domínio em todos os canonical e og:url (ver seção 11)
  2. Configure o Google Analytics com o domínio real
  3. Envie o sitemap ao Google Search Console
  4. Teste o formulário de contato com EmailJS
